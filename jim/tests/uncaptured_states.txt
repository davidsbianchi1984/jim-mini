# status: backlog — 2 rows
#
# Gallery screens the camera cannot yet photograph, and why each one.
#
# The gallery has two kinds of screen. A *page* is what a nav tab opens, and
# `tools/shoot_screens.py` has always been able to photograph one. A *state*
# is something the census numbers separately — `Coach 14,24,82`, `Baseline
# 38,81` — because a component draws more than one thing a person meets.
# Until this round the camera could reach a page and nothing smaller, so
# every state in the gallery was a drawing, and a drawing is what fills a
# gap nobody can photograph.
#
#     asked     can the camera reach every page
#     mattered  can it reach everything the gallery numbers
#
# A state is now found by `data-screen="<number>"` on the element that owns
# it, and a page that no tab opens by a recipe naming the press that gets
# there. Seven came off this list — 83, 87, 93, 107, 38, 111 and 14. These three are what is left, each with the specific thing
# standing in the way rather than a shrug.
#
# The number never goes up. A new component that owns a numbered state
# either carries its marker or does not ship.

105  Feed · what this tab won't do
     The card is `{view && ...}` and `view` comes from
     GET /community/{id}/feed, which answers 409 for the harness's freshly
     enrolled account: it has no QRME tandem, so there is no community feed
     to describe and nothing for the card to say. Reaching it means teaching
     `enrol()` to link a tandem first, which is a larger change than this
     round made. The camera refused rather than writing the empty state
     under a number that means something else.

82   Coach · coach out loud
     Not a separate element. It is the *listening* state of the same card
     screen 24 already shows — `<button className={listening ? "mic
     listening" : "mic"}>` — so a marker on the card would photograph 24
     again under 82's number. Reaching it means holding the microphone
     open, and the browser this camera drives has no speech recogniser
     behind it; what it would capture is a button mid-press, not the screen
     the drawing shows.
