# Gallery screens the camera cannot yet photograph, and why each one.
#
# The gallery has two kinds of screen. A *page* is what a nav tab opens and
# `tools/shoot_screens.py` has always been able to photograph one. A *state*
# is something the census numbers separately — `Coach 14,24,82`, `Baseline
# 38,81` — because a component draws more than one thing a person meets.
# Until this round the camera could reach a page and nothing smaller, so
# every state in the gallery was a drawing, and a drawing is what fills a
# gap nobody can photograph.
#
#     asked     can the camera reach every page
#     mattered  can it reach everything the gallery numbers
#
# The camera now photographs a state by the `data-screen="<number>"` marker
# on the element that owns it — the same shape as the `data-tab` the nav has
# always carried, and for the same reason: a marker in the markup is a thing
# the camera and the reader can both check, where a selector guessed from
# outside silently starts matching the wrong card. Four states came off this
# list the day it was written (83, 87, 93, 107). These five are what is left,
# each with the specific thing standing in the way rather than a shrug.
#
# The number never goes up. A new component that owns a numbered state
# either carries its marker or does not ship.

105  Feed · what this tab won't do
     The card is `{view && ...}`, and `view` comes from
     GET /community/{id}/feed, which answers 409 for the harness's freshly
     enrolled account — it has no QRME tandem, so there is no community
     feed to describe. Reaching it needs the enrolment to link a tandem
     first, which is a bigger change to `enrol()` than this round made.
     The camera refused rather than writing the empty-state card under a
     number that means something else.

111  Studio · widgets
     Not a nav tab: it is reached from the Talk screen's launcher tiles
     (`Talk.tsx`, `{ id: "studio", icon: "🛠" }`). A page, not a state, so
     it wants an `INSIDE` recipe rather than a marker — the mechanism for
     that exists and this screen has not been given one yet.
