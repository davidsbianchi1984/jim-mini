# Every interpolation into markup whose value the sweep cannot see reach an
# escape. Written by `test_a_page_never_prints_what_it_was_given.py`.
#
# ## Why these are recorded rather than fixed
#
# 0.59.3 found reflected cross-site scripting on the sign-in callback:
# `?error=<script>…` went straight into the page. It had been there for four
# hundred releases, and what made it invisible was not that it was hard to
# see — it is three lines of obvious — but that **nothing was looking**. The
# escaping is the first line of defence; the Content-Security-Policy shipped
# in the same round is the second.
#
#     asked     is this page correct
#     mattered  can the next value somebody interpolates be markup
#
# Every row below is a composite the analysis cannot follow — a body assembled
# from parts that were each escaped where they were built, a stylesheet
# constant, a fragment returned by a helper with several branches. Each was
# read once and written down here. None is a value a reader supplies.
#
# ## What the sweep does follow
#
# Single assignments (`ref = html.escape(...)` then `{ref}`), functions whose
# every return is escaped, conditionals and joins whose every branch is safe,
# and numeric calls. Without that, the same sweep reports 32 rows in QRME
# instead of eight, and a record that is four-fifths noise is a record nobody
# reads.
#
# It does not read prose as markup: `http://localhost:<port>` in a WebAuthn
# diagnostic is a sentence, and the first draft called it a page.
#
# ## How a row leaves this file
#
# Escape the value where it is interpolated, or restructure so the analysis
# can follow it. The ceiling does not move up: a new row is a value somebody
# can put markup into.
#
#
# ## What changed when the sweep learned two scopes
#
# Three of the rows this file carried were never defects. The sweep scanned
# every f-string **twice** — once inside its own function, once in a pass that
# walked the whole module — and reported the union. Each pass had a blind spot
# the other did not, so each pass's blind spot became a permanent row:
#
# * the per-function pass could not see a **module-level constant**, so a
#   stylesheet or a template interpolated inside a function was an
#   unresolvable name;
# * the module-wide pass merged **every function's assignments into one
#   table**, so a name written safely in one function and unsafely in another
#   took the unsafe binding — and was reported at the line that is correct.
#
#     asked     is this interpolation safe
#     mattered  is the name being read the one that is written there
#
# Each function is scanned once now, in a scope seeded with the module's own
# bindings, and the module pass scans only what is not inside a function.
#
# The rest left by being made visibly safe rather than argued safe in this
# file: a count became `int(...)`, a class name from a fixed table is escaped
# where it lands, and a cooldown returns `int(...)`. Each was already correct
# and now says so where it is written.
#
# This mattered more than a few rows. A security record is read by somebody
# deciding whether to look closer, and this file says of itself that a record
# four-fifths noise is a record nobody reads. Rows that cannot be resolved by
# reading the code are how that begins.
#
