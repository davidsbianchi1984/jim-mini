# English refusals — the sentences the Guardian says when it says no.
# Checked by test_the_guardian_refuses_in_one_language.py, both directions,
# and ratcheted.
#
# jim/i18n.py opens with "everything the Guardian drafts or delivers,
# localized", and is specific about the part that matters most: deterministic
# safety content is hand-translated here, and *safety text is never
# machine-mangled*. The playbooks are translated. The pace cues are. The
# waiver terms are.
#
# The sentences it says when it refuses were English — all sixty-four,
# including every refusal the medication cabinet, the vigil, the crash watch
# and the watch bridge can produce.
#
#     asked     is the safety content the Guardian drafts translated
#     mattered  is the safety content it refuses with
#
# As of this release every constant refusal in this product is translated
# into all nine. The count this file carried went 92 → 42 → 0; what is left
# below the line is the part that is not a count.
#
# ## What this file does not cover
#
# **18 f-string refusals**, down from 25. Sentences built by
# interpolation cannot be keyed on their English source, because at the moment
# they are raised there is no English source — only a result.
#
#     asked     is the refusal a constant we can translate
#     mattered  is every part of it something we can translate
#
# `i18n.Templated` now carries the template and its slots alongside the
# finished English sentence, and 7 sites were converted. What decides
# whether a site can be is the *slot*, not the frame: a slot holding a token —
# `en, es, pt`, `openai` — is the same string in every language and is safe to
# drop into a translated frame; a slot holding prose is not, and a translated
# frame around an English slot is worse than an English sentence, because it
# reads as a bug in front of somebody who is already being told no.
#
# The mechanism refuses rather than guesses: a slot that fails the whitespace
# test keeps the whole refusal English, so a half-translated sentence is not
# something a future round can produce by accident. See
# `test_a_refusal_whose_english_is_not_a_constant`.
#
# Named here rather than counted in, so the zero above cannot be read as
# meaning there is no English left anywhere.
#
#
# ## 0.80.0: the sentences behind `str(exc)`
#
# This file rested on a guard that walked `HTTPException` call sites and
# stopped there. The routes that refuse by forwarding a domain exception —
# `except SomeError as exc: raise HTTPException(409, str(exc))` — carry a
# sentence that lives at the `raise` in a module the guard never opened.
#
#     asked     what does this route pass to HTTPException
#     mattered  where does the sentence it passes come from
#
# The 92 rows this file grew that release were what following those forwards
# found. They were not new English; they were English this file had been
# unable to see for as long as it had existed. `tr_refusal` treated them
# identically to a directly-raised literal: it looked the sentence up, missed,
# and served English.
#
# Found in QRME first and measured here the same day — all three products
# had it, which is what this estate keeps finding when a guard is written
# once and never asked whether its siblings need it too.
#
#
# ## Not refusals: sentences raised while the app is wired
#
# The collector derives the exception classes to follow from the handlers
# that stringify them. `ValueError` is correctly among them — plenty of real
# refusals are raised as one — and the sweep then took *every* raise of that
# class in the package, constructors included.
#
#     asked     is this sentence raised through a class a route stringifies
#     mattered  can a person reach the place it is raised
#
# These 3 were never owed a translation. Each fires in an `__init__`,
# from environment variables, while the app is being built: there is no
# object yet, no request to answer and no reader — if one ever fired the
# process would not start. They left this backlog without being translated
# because they were never in it by right.
#
#   CloudModelClient needs base_url or a client
#   PDIClient needs base_url or an injected client
#   QRMEClient needs base_url or an injected client
#
# `_constructor_sentences` applies the exemption and
# `test_a_wiring_precondition_is_not_a_refusal` checks it in both
# directions — forward, that each really is raised inside a constructor;
# backward, that none is *also* raised where a request can reach it. An
# exemption nothing verifies is a place to hide sentences that are owed.
