# Every numeric floor in this suite still carrying its own literal: an
# `assert <something> > <int>` with the number written into the assertion.
#
# ## What this counts, and why counting it is the point
#
# A floor answers one question every run — is the number satisfied — and that
# is exactly the question that keeps passing after the number stops meaning
# anything. Asking the second question, *is it still near what it measures*,
# needs the measurement, and a literal inside an assertion has none attached.
#
#     asked     is the number satisfied
#     mattered  is the number still near what it measures
#
# 0.58.8 found the route reader's floor was written when the console was the
# only client. 0.58.9 found the localizer's was ten against nine hundred and
# forty-five in the largest product. 0.59.0 applied the standard to everything
# reachable, in all three:
#
#     l10n asked, per shell        10 against 279-312      ratio 0.04
#     l10n held, per shell         20 against 286-312      ratio 0.07
#     path literals, all surfaces  40 against 466          ratio 0.09
#     native call sites            20 against 113-114      ratio 0.18
#     console call sites          200 against 251          ratio 0.80  held
#
# The rows that passed are as informative as the ones that did not. A literal
# copied into three repositories is calibrated for whichever of them was
# smallest when it was written, so the same number is an honest floor in one
# product and decoration in another — and nothing in either could tell,
# because neither had the measurement attached.
#
# Those are now in `ratchets.py`, registered with the way to measure the same
# quantity, and audited every run. The rows below are what is left.
#
# ## How a row leaves this file
#
# Register it in `ratchets.py` with a `measure` callable and change the
# assertion to `ratchets.floor("name")`. The sweep finds bare literals only,
# so registering removes the row without anybody editing this list — and the
# registered floor is then checked against reality on every run.
#
# Not every row here is wrong. Some of these numbers are small fixed
# cardinalities that will never drift. Telling those apart from the decoration
# requires knowing what each one measures, which is the work of registering
# it, which is why they are counted rather than guessed at.
#
# The ceiling does not move up because a floor was written. It moved up once,
# here, because the sweep was widened — and the distinction is the whole
# reason a number like this is worth keeping.
#
#     asked     did the backlog grow
#     mattered  did the suite get worse, or did the instrument get better
#
# The sweep used to take any comparison against an integer of five or more.
# Five stood in for "is this a floor at all", badly: it hid an `assert n >= 2`
# over a shell building a hundred and twenty-seven requests, and lowering it
# would have swept in fifty-two assertions about single response bodies that
# no ratchet could ever measure. It now asks what the left side of the
# comparison is — a count of something the suite went and found, or a value
# pulled out of what something returned.
#
# Rows that appeared the day that changed were always there. A backlog that
# only ever falls, when the thing generating it can be narrowed, is a number
# about the sweep rather than about the suite.
#
#
# ## Not floors: a value that is not a size
#
# The sweep matches the *shape* `assert <something> >= <int>`. Some of what
# it caught is not a floor on anything that can grow — it is a value read out
# of a response or a fixture, compared against a number that means something
# else entirely.
#
#     asked     is this an `assert x >= <int>`
#     mattered  is the int a floor on something that can grow
#
# `refused.status_code >= 400` is the clearest. The 400 is not a size and
# there is no "four-fifths of what is actually there" to raise it toward; it
# asks whether the response was a refusal at all. Registering a ratchet for
# it would produce a floor that could never be audited, which is the thing
# this whole file exists against.
#
# Two of these arrived with the widened sweep, and both are the shape the
# old size cutoff used to hide by accident. `comma` is a character index into
# a Kotlin source — the assertion is that a comma was found before the
# closing brace, and the number it is compared against is a position, not a
# size. `step` is a slider's increment, where the assertion is that the
# control moves at all. Neither has four-fifths of anything to be raised
# toward.
#
# The others are the same in their own domains. The watch one is not even a
# minimum: 60 is enrollment's default resting rate, and the assertion is that
# the baseline *moved off it* toward the real history — a direction, written
# as a comparison. The vigil's 48 counts hours of real quiet after the
# fixture ages its events by three days. `samples >= 6` follows a loop that
# posts exactly six readings, so it asks whether all six landed.
#
# Each is exempted by `file.py: expr` rather than by line, because a line
# number is a fact about today's file — paying down eighteen floors in this
# suite moved five unrelated rows by one line each, and an exemption keyed on
# a line would have silently started covering whatever slid into the slot.
# One row can therefore cover two identical assertions in the same file,
# which is why five rows remove six comparisons.
#
#   test_a_conversation_you_can_take_with_you.py: comma > 0
#   test_emergency.py: med['age'] >= 40
#   test_the_baseline_screen_is_the_home_of_limits.py: step > 0
#   test_the_guardian_refuses_in_one_language.py: refused.status_code >= 400
#   test_the_watch_you_actually_wear.py: metrics['resting_heart_rate']['value'] > 60
#   test_vigil.py: st['silent_hours'] >= 48
#   test_watch.py: metrics['heart_rate']['samples'] >= 6
#
# `test_every_exempted_comparison_is_still_there` checks each is really
# written somewhere, and `test_a_count_can_never_be_exempted` checks the
# direction that matters: a comparison against `len(...)` or `sum(...)` is a
# count of a swept surface, is always a floor, and may not be excused here
# however convincing the prose above it. An exemption nothing verifies is a
# place to hide the numbers this file is meant to find.
